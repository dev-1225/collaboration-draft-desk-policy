Privacy policy

About this project

Collaboration Draft Desk is a personal, single-user research and writing application. The current desktop application is named Collaboration Network Assistant, version 0.2.0. It runs on the user's computer at localhost:3000. This policy describes that application and this documentation website.

The project operator maintains the software and these documents. The local application does not send the operator a copy of your workspace.

Information the application uses

  • Research: public Cisco/Webex feed excerpts, GitHub repository details, source URLs, tags, and references you enter.
  • Your work: saved ideas, writing notes, post drafts, publication records you enter manually, and preferences.
  • Private notes: contact labels, context, and conversation notes that you choose to save. The app does not import LinkedIn contacts.
  • Measurements: LinkedIn impressions and other measurements you enter manually, together with their dates and scope. The app does not retrieve live LinkedIn analytics.
  • Reply helper: a comment or message you voluntarily paste, your perspective, and the generated reply. These fields are held in the current editor and processed locally when you request a suggestion; the application does not save them to its workspace database.

Why information is used

The application uses this information to discover public technical references, organize your research, generate editable writing suggestions, save your work, record manual publication, and compare measurements you provide. It does not sell or rent workspace information, use it for advertising, or include advertising trackers or third-party usage analytics.

Local storage and backups

Saved workspace records are stored in a SQLite file on the computer running the application. The default location is data/assistant.sqlite within the project folder. The database may have SQLite journal or sidecar files. The application does not encrypt this workspace database or exported JSON backups.

Exporting creates a JSON backup containing your saved workspace, including private notes. Importing a backup replaces the current workspace after confirmation. File locations, Windows account access, device backups, browser state, and any copies you create are under your control. Saved records are retained until you delete or replace them.

Public sources and external links

When you click Refresh sources, the application can request the enabled public Cisco/Webex RSS feeds and the GitHub public repository search API. Those requests expose ordinary connection information, such as the connecting device's public IP address and request headers, to the source providers. The GitHub adapter uses a fixed technical search query; it does not send private notes, drafts, or pasted messages.

Manually entered research links are stored as references and are not automatically fetched. Opening an external link, including LinkedIn, takes you to that provider in your browser. The provider's own privacy policy applies to your activity there.

Optional local AI

Editable templates work without an AI model. If you enable Local Ollama, checking models contacts the local Ollama service. When you click Generate, the application sends the relevant draft notes and selected source excerpt, or the pasted reply-helper text and your perspective, to the configured installed model through http://127.0.0.1:11434.

The application excludes models identified as cloud or remote models and does not call a paid cloud model API or download models automatically. The local Ollama installation, model behavior, and its own configuration or logs are separate from this application. Generated text is a suggestion for you to review; it can be inaccurate.

LinkedIn connection: current status

Version 0.2.0 has no working LinkedIn OAuth connection or API publishing feature. It does not collect LinkedIn passwords, client secrets, access tokens, or profile data through LinkedIn APIs. It does not read feeds, scrape profiles, access inboxes, send messages, or publish posts.

The current workflow lets you copy a draft, open LinkedIn yourself, publish manually, and record the result in the local workspace. A future authorized API integration is planned but is not active. Before any such feature is enabled, this policy and the application's consent information must be updated to describe its actual data access, token handling, retention, disconnect controls, and publication behavior.

Your choices and deletion

  • Review, edit, or delete saved records through the application. Some related records must be removed first to preserve the integrity of saved work.
  • Use Settings to export a backup, restore a chosen backup, disable sources, turn local AI off, or reset the workspace by typing RESET LOCAL DATA.
  • Resetting clears application records and restores default preferences. It does not delete JSON exports, device or cloud backups, browser copies, local AI logs, or posts you already published on LinkedIn.
  • Deleting records or resetting SQLite is not a promise of forensic erasure. To remove all remaining local files, close the application and manage its data folder and any copies through your operating system. Manage posts and other provider-held data directly with the relevant provider.

Security and sensitive information

The application is intended for a single user on a protected local computer, rather than public server hosting. Use operating-system access controls and protect exported backups. Do not enter passwords, access tokens, confidential employer information, or other people's private information unless you are authorized and the information is necessary.

Local request checks reduce accidental cross-site access, but no software can promise absolute security. A report to the project operator should describe the issue without including secrets or private workspace content.

This documentation website

This static website presents the project's privacy policy and user terms. It has no forms, advertising scripts, analytics scripts, or access to your local workspace. It does not ask for LinkedIn credentials.

When hosted on GitHub Pages, GitHub logs visitors' IP addresses for security. GitHub's privacy practices apply to hosting, GitHub sign-in, and any issue you submit. Visiting these policy pages does not upload the application's SQLite database or your drafts.

Contact and requests

Use the project's GitHub issue page to contact the project operator about this policy, privacy questions, deletion instructions, or a security concern. Issues are public; describe the request without adding personal notes, credentials, pasted private messages, or other confidential information.

For the current local-only application, the operator does not hold a server copy of your workspace. You can use the deletion controls described above without contacting anyone.
